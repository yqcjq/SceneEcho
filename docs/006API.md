# 接口导览

> 🚧 **本文档处于占位 / 起步状态**——只列出当前已有的端点骨架与典型用户流程；详细字段请直接查 FastAPI 自动生成的交互式文档：开发态启动后端后访问 `http://localhost:18521/docs`（Swagger UI）或 `http://localhost:18521/openapi.json`（机器可读 schema）。
>
> **本文档定位**：给外部接入方一条"按用户流程串起来"的导览线，让人看完就知道"想完成 X 该按什么顺序调哪几个接口"，**不**复制 OpenAPI 已经描述好的请求 / 响应字段（那只会过时）。
>
> 接口实现位于 `backend/app/api/`，每个文件对应一个资源域；新增接口先决定它属于哪个文件。

---

## 命名约定

- 所有 HTTP 接口路径以 `/api/` 开头（由 FastAPI 路由前缀统一加），SSE 事件流也走 `/api/`。
- 所有素材 / 渲染产物 / 缩略图通过 `/data/<相对路径>` 静态访问，文件实际落在 `DATA_ROOT` 目录下（默认 `backend/data/`）。
- 任务异步的接口（上传、提取、应用、渲染、编辑）都立刻返回 `task_id`，调用方再用 `GET /api/tasks/{task_id}` 轮询状态、或订阅 `GET /api/tasks/{task_id}/events` 看事件流。

## 典型用户流程

### 流程 A：上传一段样例视频，看一个最小渲染 demo

1. `POST /api/samples`（multipart 上传 mp4）——拷贝原文件、调 ffmpeg 归一化、抽缩略图，返回 `sample_id`。
2. `POST /api/samples/{sample_id}/render-demo`——构造一个最小项目数据并送去渲染，返回 `task_id`。
3. `GET /api/tasks/{task_id}` 轮询直到 `status=completed`，结果里带渲染产物的 `/data/...` 路径。

涉及文件：`api/samples.py`、`api/tasks.py`、`api/projects.py`（render-demo 复用项目渲染入口）。

### 流程 B：把样例视频提取成可复用模板

1. `POST /api/samples/{sample_id}/extract`——后台跑视频识别管线，返回 `task_id`。
2. `GET /api/tasks/{task_id}/events`（SSE）——实时观看每个识别子能力的决策事件；前端的"工作台"页面就是它。
3. 完成后 `GET /api/templates`—列出所有模板；`GET /api/templates/{template_id}` 取详情；`PATCH /api/templates/{template_id}` 改标签 / 字幕占位。

涉及文件：`api/samples.py`（extract）、`api/events.py`（SSE）、`api/templates.py`。

### 流程 C：用户素材 + 模板 → 出片

1. `POST /api/projects`（multipart 上传）——拷贝用户素材并归一化，返回 `project_id`。
2. `POST /api/projects/{project_id}/recommend-templates`——后端跑语音识别 + 模板推荐，返回 top-k 模板列表与中文理由。
3. `POST /api/projects/{project_id}/apply`（body 含选中的 `template_id`）——后端跑装配管线（绑定 / 缺口 / 补缺 / 上样式 / 选 BGM），返回 `task_id`；完成后项目数据写到 `DATA_ROOT/projects/{project_id}/project.json`。
4. `GET /api/projects/{project_id}/preview-props`——给前端实时预览组件用的精简数据。
5. `POST /api/projects/{project_id}/render`——发起最终 MP4 渲染，返回 `task_id`；轮询 / 看事件流均可。

涉及文件：`api/projects.py`、`api/tasks.py`、`api/events.py`。

### 流程 D：编辑已生成的项目（自然语言 / 参数面板）

1. `POST /api/projects/{project_id}/edit`（body：`{"instruction": "..."}`）——自然语言编辑：后端调 LLM 把指令翻成结构化编辑操作并应用，自动触发重渲染，返回 `task_id` + 新一轮渲染的 `task_id`。
2. `POST /api/projects/{project_id}/panel-edit`（body 是结构化编辑操作数组）——前端参数面板直接传操作，跳过自然语言翻译。
3. `POST /api/projects/{project_id}/undo`——弹出最近一次编辑前的快照写回，自动触发重渲染。
4. `GET /api/projects/{project_id}/history`——按时间倒序列出本项目的全部编辑记录。

涉及文件：`api/edit.py`、`agent/nl_edit.py`、`render/throttle.py`（自动取消旧渲染）。

### 流程 E：实时观看与历史回放 AI 决策

- **实时**：`GET /api/tasks/{task_id}/events`（SSE）——长连接订阅一个任务的事件流；每条消息是一次 AI 决策（输入摘要、输出、要写入哪份数据的哪个字段、严重度、因果链）。
- **历史**：`GET /api/tasks/{task_id}/events/history?from_event_id=...&until_seq=...`——按区间拉取已落盘的事件 JSONL。
- **复盘**：`GET /api/projects/{project_id}/replay/events?task_id=...` 与 `GET /api/samples/{sample_id}/replay/events?task_id=...`——按资源 id 找到目标任务，一次拉全量事件。
- **任意时刻快照**：`POST /api/projects/{project_id}/replay/snapshot {"task_id": ..., "sequence": N}`——重放前 N 条事件，返回那个时刻的中间产物。

涉及文件：`api/events.py`、`api/replay.py`、`event_bus.py`。

### 流程 F：跨页面导航（按资源查任务）

- `GET /api/samples/{sample_id}/tasks`——按时间倒序列出该样例发生过的所有任务（提取、试渲染等）。
- `GET /api/projects/{project_id}/tasks`——同上，针对项目（推荐、应用、渲染、编辑、撤销等）。
- `GET /api/projects/{project_id}/lineage`——返回项目装配时用到的样例 id 与模板 id（"族谱"）。

涉及文件：`api/samples.py`、`api/projects.py`。

## 开发模式专用接口

以下接口仅在 `.env` 设置 `ENABLE_DEV_MOCK=true` 时挂载，生产构建会 403。

- `GET /api/dev/workbench/scenarios`、`POST /api/dev/workbench/mock-stream`——在没有真实 VLM 时让前端工作台跑一段假事件，用于联调三栏 UI。
- `GET /api/lab/subcaps`、`POST /api/lab/run-subcap/{name}`、`GET /api/lab/baseline/{name}`——单点能力实验室：选一个识别子能力 + 一份样例跑一次，对照基线 JSON。

涉及文件：`api/dev_workbench.py`、`api/lab.py`。

## 渲染器内部回调

以下接口由 `renderer/` 渲染服务回调使用，外部调用方不要直接调。

- `POST /api/internal/task-progress`——渲染服务把进度百分比与阶段名写回任务表。

涉及文件：`api/tasks.py`。
