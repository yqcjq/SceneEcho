# 缩放方向 + 平移粗判（1A.zoom_direction）

你看到的是一段镜头内三张采样帧（首 / 中 / 末），左上角带 "first" / "mid" / "last" 标识。请判断**这一镜头内**画面缩放（zoom）+ 平移（pan）的整体方向，按以下 JSON Schema 输出。

## 输出 JSON Schema

```json
{
  "direction": "推进" | "拉远" | "稳定" | "抖动" | "左移" | "右移" | "上移" | "下移" | "左上移" | "右上移" | "左下移" | "右下移",
  "confidence": 0.0-1.0,
  "reasoning": "≤200 字中文解释，引用三帧画面差异"
}
```

## 13 类方向定义

### 缩放（视野范围变化）
- `推进`：last 帧主体在画面中占比明显大于 first（zoom in / 视野收窄）。
- `拉远`：last 帧主体占比小于 first（zoom out / 视野扩大）。
- `稳定`：三帧视野范围基本不变，仅有微小晃动 / 物体内部移动。
- `抖动`：缩放反复（first→mid 推进 mid→last 拉远等），无明确方向。

### 平移（视野范围不变，画面整体水平 / 垂直 / 斜向移动）
- `左移`：画面整体向左平移——first 帧的右侧内容在 last 帧出现在画面中间或左侧。
- `右移`：画面整体向右平移——first 帧的左侧内容在 last 帧出现在画面中间或右侧。
- `上移`：画面整体向上平移——first 帧的下方内容在 last 帧出现在画面中间或上方。
- `下移`：画面整体向下平移——first 帧的上方内容在 last 帧出现在画面中间或下方。
- `左上移` / `右上移` / `左下移` / `右下移`：对角斜向平移（同时具有水平 + 垂直分量）。

## 示例

- 镜头从一个人脸正面慢慢拉近 → `推进`。
- 镜头从全景拉到只剩一个产品特写 → `推进`。
- 镜头从产品特写慢慢退到全景 → `拉远`。
- 镜头几乎静止，主体小幅晃动 → `稳定`。
- 镜头沿着一行字从左往右扫读 → `右移`。
- 镜头随手持运镜从主体右上方扫到左下方 → `左下移`。

## 关键约束

- **缩放与平移互斥**：同时存在缩放 + 平移时，按主导方向二选一——视野范围变化是主信号归推进 / 拉远 / 抖动，画面整体位移是主信号归 8 平移类之一。
- 不要被画面内的物体运动 / 人物动作误导。focus 在镜头自身视角变化（视野广角 vs 局部 / 整体位移）。
- 平移幅度小于画面 5%（一只手抖动级别）按 `稳定` 处理。
- `confidence < 0.6` 时倾向标 `稳定`，让下游 CV 用光流验证细节。
