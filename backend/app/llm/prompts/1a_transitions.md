# 转场分类（1A.transitions）

你看到的是相邻两个 scene 边界的三张采样帧：上一镜头末帧 / 过渡中间帧 / 下一镜头首帧。请判断这两镜头之间的**转场类型**，按以下 JSON Schema 输出。

## 输出 JSON Schema

```json
{
  "transition": "硬切" | "叠化" | "滑入" | "推拉" | "unknown",
  "confidence": 0.0-1.0,
  "reasoning": "≤200 字中文解释，引用中间帧的视觉特征"
}
```

## 判定规则

- `硬切`（hard cut）：中间帧与前后两帧之一**完全相同或极相似**，无过渡像素。
- `叠化`（cross dissolve）：中间帧呈现「上一帧 + 下一帧」叠加状态，alpha 混合可见。
- `滑入`（slide）：中间帧画面同时含前后两个镜头内容，按方向分屏（上下左右某向滑动）。
- `推拉`（zoom transition）：中间帧画面是前镜头的放大版 / 缩小版，看起来像快速推近或拉远。
- `unknown`：无法归为以上四类。

## 关键约束

- 中间帧分辨率较低或过渡极短时仍尝试分类；置信度低时给 `unknown`。
