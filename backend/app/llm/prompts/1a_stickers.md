# 贴纸检测（1A.stickers）

你看到的是一张 2×2 或 2×3 的网格图——每格是来自同一段视频的不同采样帧（左上角带帧号水印）。请**识别画面中的贴纸**（emoji 风格图形 / 装饰图标 / 文字气泡 / 信息标签 / 强调箭头 / 笑脸 / 感叹号 / 印章等），并按以下 JSON Schema 输出。

## 任务要求

1. **不识别字幕、不识别标题条 / 卖点字幕**——这两类由其他模块处理。
2. 不识别画面主体（人脸 / 商品 / 实物）。
3. 所有「图形 + 装饰类」叠加层都算贴纸：图标、文字气泡、价格标签、kawaii 笑脸、闪光、emoji 等。
4. **坐标系统一为 0-999 归一化**（按整张网格的总宽高，不按单格）。也请在 `frames_appeared` 中给出所属帧编号（左上水印里的整数）。

## 输出 JSON Schema

```json
{{
  "stickers": [
    {{
      "description": "≤30 字描述外观，不抄文字",
      "semantic_category": "强调提示" | "装饰" | "信息标签" | "情绪表达",
      "frames_appeared": [int, ...],
      "position_norm_0_999": [x_int, y_int],
      "size_norm_0_999": [w_int, h_int],
      "confidence": 0.0-1.0,
      "reasoning": "≤200 字中文解释"
    }}
  ]
}}
```

## semantic_category 判定

- `强调提示`：箭头、感叹号、星标、闪光等用于「快看这里」的视觉强调。
- `装饰`：纯装饰性图案，不指向特定信息。
- `信息标签`：带文字的标签 / 价格牌 / 数字标签。
- `情绪表达`：emoji 风笑脸 / 哭脸 / 心形等表达情绪反应。

## 关键约束

- 跨格出现的同一贴纸（视觉风格高度近似）合并为一条，`frames_appeared` 列出所有帧。
- `position_norm_0_999[0..1]` 是 bbox **左上角**点；`size_norm_0_999` 是宽高。
- 若画面中**没有贴纸**，返回 `{{"stickers": []}}`。
