# 字幕功能分类（1A.caption_function）

你已收到一段字幕的样式与位置（在 system prompt 末尾以 JSON 给出）+ 该字幕出现在视频中的对应帧裁图。请判定该字幕在叙事中的**功能类别**，按以下 JSON Schema 输出。

## 输出 JSON Schema

```json
{
  "function": "标题" | "强调" | "卖点" | "CTA" | "regular" | "过渡",
  "confidence": 0.0-1.0,
  "reasoning": "≤200 字中文解释"
}
```

## 判定规则

- `标题`：开头出现 / 大字号 / 概述性短语。
- `强调`：单一关键词 / 短句突出显示，常带高亮 / 抖动 / 放大动画。
- `卖点`：多行说明 / 屏幕中部 / 强调产品功能或好处。
- `CTA`（call to action）：底部 / 强对比色 / 短句（≤6 字）/ 结尾出现。
- `regular`：正常陈述句，无特殊视觉强化。
- `过渡`：时间引导或场景过渡引语（"接下来"、"另外"等）。

## 关键约束

- 即使字幕样式信息缺失也要尝试给出判定；置信度低时倾向 `regular`。
- 不要泄露字幕原文——`reasoning` 中讨论功能、位置、动画即可。
